# 中国水污染监测数据分析项目

> 杨、韩、贺组 高二数据分析比赛项目

## 项目简介

本项目对中国水污染监测数据集进行全面的探索性数据分析（EDA），旨在识别水质问题、分析污染模式，并提供数据驱动的环境保护建议。

**数据概况：**
- 📊 覆盖 10 个省份、18 个城市、180 个监测站点
- 📅 时间跨度：2023年1月 - 2024年12月
- 🔍 监测记录：15,524 条（预处理后）
- 🧪 分析指标：16 项水质指标（pH值、溶解氧、重金属等）

## 核心功能

### 数据预处理 (`preprocess.py`)
- ✨ **异常值检测与清洗**：结合 3-sigma 和 IQR 方法
- 🔄 **编码自适应处理**：自动识别 UTF-8/GBK 编码
- 🗺️ **地理编码**：集成高德地图 API 获取城市坐标（可选功能）

### 探索性数据分析 (`eda.py`)
生成 10 类专业可视化图表：

1. **基础统计** - 污染等级分布 + 省份记录量 TOP10
2. **指标分布** - 16 项水质指标的分布特征
3. **区域分析** - 各省市水质指数对比
4. **时间分析** - 季节性趋势与年度变化
5. **相关性矩阵** - 水质指标间的关联关系
6. **污染物影响** - WQI 与关键污染物的散点分析
7. **重金属分析** - 铅/镉/汞超标情况
8. **营养污染** - 氮磷污染与富营养化风险
9. **有机污染** - COD/BOD 污染程度评估
10. **物理参数** - 温度/pH/浊度/电导率分析

### 分析工具
- **数据质量检查** (`data_quality_check.py`)：检测缺失值、重复记录
- **范围确定** (`determine_ranges.py`)：基于预处理数据确定各指标的合理区间

## 核心发现

### 水质概况
- ✅ **良好及以上**：72.76% (优秀 19.42% + 良好 53.34%)
- ⚠️ **污染情况**：27.24% (中等 20.27% + 较差 3.44% + 很差 3.54%)

### 主要污染源
1. **化学需氧量（COD）** - 与 WQI 相关性最高 (0.118)
2. **浊度** - 次要影响因子 (0.034)
3. **总磷/总氮** - 富营养化风险 57.57%
4. **重金属** - 铅超标 11 例 (0.07%)

### 区域特征
- 🔴 **高污染区域**：广东省（平均 WQI 35.78，"很差"记录 66 条）
- 📉 **溶解氧不足**：15.74% 的监测点 DO < 6 mg/L

### 季节规律
- 夏季水质指数略高（35.55）
- 秋季水质相对较好（34.74）

## 环境建议

基于分析结果，项目提出以下建议：

1. 🏭 **重点治理高污染区域的有机污染**（COD/BOD 控制）
2. 🚫 **加强氮磷排放管控**，遏制富营养化趋势
3. 🔬 **重金属源头监测**，尤其在高风险省份
4. 💧 **提升污水处理能力**，改善城市水质
5. 📊 **建立季节性监测策略**，根据季节特征优化监测频次
