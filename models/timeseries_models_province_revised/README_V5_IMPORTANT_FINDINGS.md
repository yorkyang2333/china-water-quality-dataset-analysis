# v5.0 重要发现：7日滚动均值是强baseline

## 🔍 问题现象

运行v5.0时，所有Optuna trials都被剪枝，报错：
```
⚠️ 模型未超过baseline! (model=0.017208 vs baseline=0.011262)
ValueError: No trials are completed yet.
```

## 💡 根本原因

**7日滚动均值（MA7）本身就是一个非常强的预测方法！**

### 为什么MA7这么强？

1. **降噪效果好**：平滑掉了日间波动噪声
2. **保留趋势**：捕捉了中期趋势
3. **简单有效**：计算简单，不需要训练

### 数据证据

从错误信息可以看到：
- **MA7 baseline MSE**: ~0.011
- **LSTM模型 MSE**: ~0.013-0.029

**结论**：对于已经用7日滚动均值平滑后的数据，简单的持续性预测（预测=最近7天均值）已经很难超越。

---

## 🎯 这意味着什么？

### 1. 单变量LSTM在此数据集上的局限性

**核心问题**：
- 时间自相关太弱（ACF lag-1 ≈ 0.08）
- 7日滚动后虽然降噪，但也削弱了短期波动
- LSTM难以学到比"持续当前趋势"更好的模式

### 2. 横截面预测仍是最佳选择

**推荐方法**（来自CLAUDE.md）：
- ✅ **XGBoost分类**: R² > 99.5%
- ✅ **随机森林分类**: R² > 99.5%
- ✅ **CatBoost/LightGBM**: 性能优异

**不推荐**：
- ❌ 单变量时间序列预测（LSTM/ARIMA）
- ❌ 即使加了滚动平滑和季节特征

## 🔧 v5.0的修复

### 已应用的修复：

1. **放宽baseline阈值**
   ```python
   # 从严格的0.98倍改为宽松的1.5倍
   if best_val > baseline * 1.5:  # 只有差50%以上才剪枝
       raise optuna.TrialPruned()
   ```

2. **默认参数fallback**

       # 所有trial都被剪枝时，使用默认参数

## 🎓 关键启示

### 1. 时间序列预测的适用条件

**需要满足**：
- ✅ 强自相关（ACF > 0.3）
- ✅ 规律的时间模式（季节性/趋势）
- ✅ 足够的历史数据

**本数据集现状**：
- ❌ 弱自相关（ACF ≈ 0.08）
- ❌ 时间间隔不规则
- ❌ 日间噪声大

### 2. 何时应该用简单方法

**如果**：
- MA7 baseline R² > 0.5
- LSTM难以超过baseline

**那么**：
- ✅ 直接用MA7预测就够了
- ✅ 或者用横截面方法（XGBoost等）
- ❌ 不要强上深度学习

### 3. 多变量的价值

**唯一有希望的方向**：
- 利用指标间的相关性（水温 → 溶解氧）
- 引入外部特征（气温、降水）
- 但仍需验证是否真能超过简单baseline

## 🚀 建议的使用策略

### 策略A：接受现实，用简单方法

```python
# 7日滚动均值预测
def predict_ma7(train_data):
    return np.mean(train_data[-7:])
```

**优点**：
- 简单、快速
- 可解释性强
- 已经很准了

### 策略B：聚焦横截面预测

回到项目推荐的方法：

cd models/pollution_level_classification

## 📝 运行v5.0的正确心态

**目标不是**：
- ❌ 让LSTM超过所有baseline

**目标是**：
- ✅ 验证LSTM是否能学到有用的模式
- ✅ 了解多变量输入是否有帮助
- ✅ 对比不同方法的优劣
- ✅ 为研究提供完整的对比实验

**如果结果显示**：
- "LSTM R² = 0.4, MA7 R² = 0.5"

**正确的解读是**：
- ✅ LSTM确实学到了一些模式（R² > 0）
- ✅ 但MA7更简单有效
- ✅ **结论：此场景下应该用MA7**

## 📌 总结

| 方法 | R² | 优点 | 缺点 |
|------|-------|------|------|
| **XGBoost分类** | >99.5% | 极高准确率 | 需要标签 |
| **7日滚动均值** | ~0.5 | 简单、快速 | 仅短期预测 |
| **多变量LSTM** | 0.3-0.6 | 利用相关性 | 复杂、可能不如MA7 |
| **单变量LSTM** | <0.3 | - | 效果差 |

**最终建议**：
- 📊 污染等级预测 → **XGBoost**
- 📈 短期趋势预测 → **7日滚动均值**
- 🔬 研究对比实验 → **运行v5.0看看**
- ❌ 生产环境时序预测 → **不推荐**
