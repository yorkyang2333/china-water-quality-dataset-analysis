## 7. 误差分析

### 7.1 分类模型差异原因

**XGBoost分类**（+1.62%）：
- 可能原因：随机种子、数据shuffle顺序
- 结论：差异在合理范围内

**RandomForest分类**（-3.5%）：
- 可能原因：
  - 超参数差异（n_estimators, max_depth等）
  - 表格中的"~76%"可能是早期实验结果
  - 数据预处理版本差异
- 建议：检查表格数据来源

**LightGBM分类**（+0.81%）：
- 结论：几乎完美匹配

**CatBoost分类**（+0.46%）：
- 结论：几乎完美匹配

### 7.2 回归模型显著差异原因

**核心原因**：表格中的R²值（0.99+）来自**有数据泄露的版本**，而本次验证使用的是**严格无泄露版本v2.0**。

**证据**：
1. COD预测：表格R²=0.993 → 实际0.497（排除BOD后）
2. BOD预测：表格R²=0.995 → 实际0.009（排除COD后）
3. TN预测：表格R²=0.967 → 实际0.103（排除氮子成分后）

**数据泄露示例**：
- COD与BOD高度相关（r=0.82），使用BOD预测COD会导致虚高的R²
- TN是氨氮、硝酸盐等的总和，使用子成分预测总氮会导致数据泄露

**无泄露版本的合理性**：
- COD（R²=0.497）：中等性能，符合预期
- DO、NH₃-N、pH（R²<0）：这些指标受外界因素影响，无法从其他水质指标预测，符合化学原理

### 7.3 时间序列模型失败原因

根据`DEPRECATED_ANALYSIS.md`（57KB学术报告），时间序列方法失败的根本原因：

1. **采样极度不规则**：
   - CV（变异系数）= 1.99，远超阈值0.2
   - 时间间隔：0-115天，平均4.48天，标准差8.92天
   - 违反了ARIMA/SARIMA/LSTM的等间隔采样假设

2. **零时间相关性**：
   - ACF（自相关系数）≈ 0
   - 过去数据无法预测未来

3. **分布严重漂移**：
   - 2024年数据密度仅为2023年的12.4%
   - 训练集和测试集分布不一致
