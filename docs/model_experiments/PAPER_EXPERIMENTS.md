## 1. 实验概述

### 1.1 研究问题

**核心问题**: 如何在不规则采样的水质监测数据上进行有效预测？

**具体挑战**:
- 采样间隔高度不规则（CV=1.99）
- 时间相关性几乎为零（ACF≈0）
- 训练/测试集分布严重漂移（2024密度=2023的12.4%）

### 1.2 研究假设

**假设H1**: 传统时间序列方法（ARIMA、LSTM）在此数据上会失败（R²<0）
**假设H2**: 横截面回归方法能取得有效性能（R²>0.5）
**假设H3**: 方法选择应基于数据特征而非惯例

### 1.3 实验设计

```
实验流程:
  数据特征诊断
      ↓
  时间序列方法（ARIMA/LSTM/混合）
      ↓
  横截面回归方法（XGBoost/RF）
      ↓
  污染分类方法（对比验证）
      ↓
  综合对比 + 消融实验
```

### 2.2 数据质量诊断

#### 2.2.1 采样不规则性

| 统计量 | 数值 | 判定标准 | 结果 |
|--------|------|----------|------|
| 变异系数(CV) | 1.99 | <0.2 规则 | ❌ 极度不规则 |
| 平均间隔 | 4.48天 | ~1天 | ❌ |
| 最大间隔 | 115天 | <7天 | ❌ |
| 0-2天占比 | 40.6% | >90% | ❌ |

**结论**: 数据**不满足**时间序列的等间隔采样假设

#### 2.2.2 时间相关性

| 指标 | ACF(lag=1) | 判定标准 | 结果 |
|------|-----------|----------|------|
| Water_Temperature_C | -0.032 | >0.3 | ❌ 无相关 |
| COD_mg_L | -0.061 | >0.3 | ❌ 无相关 |
| BOD_mg_L | -0.045 | >0.3 | ❌ 无相关 |
| Total_Nitrogen_mg_L | 0.028 | >0.3 | ❌ 无相关 |

**Ljung-Box检验**: p=0.263 > 0.05 → 无法拒绝"白噪声"假设

**结论**: 数据**不满足**时间序列的自相关假设

#### 2.2.3 分布漂移

| 年份 | 样本数 | 密度(样本/天) | 比率 |
|------|--------|--------------|------|
| 2023 | 13,811 | 37.8 | 100% |
| 2024 | 1,713 | 4.7 | 12.4% |

**KS检验**: D=0.043, p=0.089 (值域分布相似，但时间密度差8倍)

**结论**: 存在严重**协变量漂移**

| 方法类型 | 核心假设 | 本数据 | 适用性 |
|----------|----------|--------|--------|
| **时间序列** | 等间隔 + ACF>0 | CV=1.99 + ACF≈0 | ❌ 不适用 |

### 4.3 失败分析

#### 4.3.1 ARIMA失败原因

```
1. 等间隔假设违反
   - ARIMA假设 y_t, y_{t-1}, y_{t-2} 间隔相同
   - 实际间隔: 1天, 13天, 2天（高度不规则）

2. ACF≈0导致模型退化
   - 最优参数 φ ≈ 0（因为过去不相关）
   - 模型退化为 y_t ≈ c（均值预测）
   - R² ≈ 0

3. 分布漂移
   - 训练密度 37.8样本/天
   - 测试密度 4.7样本/天
   - 模型无法泛化
```

#### 4.3.2 LSTM失败原因

```
1. 滑动窗口语义错位
   - 窗口内7个样本，实际跨越 7×4.48≈31天
   - 模型以为是7个"时间步"，实际是31天
   - 学到的模式是虚假的

2. 特征语义漂移
   - 2023: "lag-1" = 1.2天前
   - 2024: "lag-1" = 9.6天前
   - 相同特征，不同含义

3. 验证集早停失效
   - 在2023稠密数据上过拟合
   - 2024稀疏数据完全不同
```

#### 4.3.3 混合模型崩溃原因

```
1. 两个坏模型的融合更差
   - LSTM R²=-0.1
   - RF R²=-0.05
   - 混合 R²=-0.3（误差叠加而非抵消）

2. 权重学习过拟合
   - 验证集仅170样本/省（太小）
   - 学到的权重在测试集失效
   - 负权重被裁剪，抹杀信息

3. 误差正相关 (ρ≈0.6)
   - 两模型的误差方向一致
   - 融合放大而非抵消
```

### 4.4 时间序列方法总结

| 维度 | 表现 | 结论 |
|------|------|------|
| **R²范围** | -0.3 到 0.07 | 全部失败（<0.3阈值） |
| **vs Naive** | 90%比Naive差 | 时间序列无价值 |
| **计算成本** | 高（GPU训练45分钟） | 投入产出比差 |
| **根本原因** | 数据不满足假设 | 方法论错误 |

**学术价值**: 作为**失败案例**，展示数据特征对方法选择的重要性

## 5. 实验2：横截面回归方法（主要方法）

### 5.1 方法设计

#### 核心思想

```
不依赖时间依赖性，而是利用水质指标间的物理化学关系

预测目标: y = f(其他指标, 时间, 空间)

关键差异:
- 不使用滞后特征（因为ACF≈0）
- 不使用滚动统计（因为不规则采样）
- 把每个样本当作独立观测
```

#### 特征设计

```python
特征类别 (共26个特征):

1. 其他水质指标 (15个)
   - 除目标指标外的所有水质指标
   - 利用物理化学关系（如COD vs BOD）

2. 工程特征 (3个)
   - Total_Heavy_Metals_ug_L (重金属总和)
   - COD_BOD_Ratio (难降解有机物比例)
   - NP_Ratio (富营养化风险)

3. 时间特征 (6个)
   - Month, Quarter (类别)
   - sin_month, cos_month (季节性循环)
   - sin_doy, cos_doy (年内循环)
   - IsWeekend (工作日/周末)

4. 空间特征 (2个)
   - Province_encoded (省份编码)
   - station_count (采样密度)
```

### 5.2 XGBoost回归配置

```python
参数:
  n_estimators: 200
  max_depth: 6
  learning_rate: 0.1
  subsample: 0.8
  colsample_bytree: 0.8
  reg_alpha: 0.1 (L1正则)
  reg_lambda: 1.0 (L2正则)

评估:
  5折分层交叉验证（按省份）
  指标: R², RMSE, MAE, MAPE
```

### 9.4 关键论点（可直接用于写作）

#### 论点1: 数据特征决定方法选择

```
"传统观点认为时间序列预测应使用ARIMA或LSTM等时间序列方法。
然而，我们的研究表明，当数据不满足时间序列的基本假设
（等间隔采样、ACF>0）时，这些方法会系统性失败（R²<0）。
相反，横截面回归方法（XGBoost）在同样的数据上取得了
R²=0.67的良好性能，性能提升0.77。
这一发现强调了数据特征诊断对方法选择的重要性。"
```

#### 论点2: ACF≈0是时间序列失败的根本原因

```
"自相关系数（ACF）衡量时间依赖性的强度。
当ACF≈0时，过去的值对未来没有预测能力，
时间序列模型退化为均值预测（R²≈0）。
我们的数据集所有指标的ACF都在±0.06范围内，
远低于时间序列方法要求的0.3阈值。
这从理论上解释了为什么所有时间序列方法都失败。"
```

#### 论点3: 横截面方法利用物理化学关系

```
"横截面回归不依赖时间依赖性，而是利用水质指标间的
物理化学关系进行预测。例如，COD与BOD高度相关（相关系数0.82），
因为它们都反映有机物污染。特征重要性分析表明，
模型学到的关系符合水化学基本原理，具有良好的可解释性。"
```

#### 论点4: 失败的学术价值

```
"虽然时间序列方法在我们的数据上完全失败，但这一负面结果
具有重要的学术价值。它系统地量化了数据特征对方法性能的影响，
并为实践者提供了明确的方法选择框架：
首先诊断数据特征（CV, ACF），然后根据诊断结果选择合适的方法。
这一框架具有普遍适用性，不局限于水质预测领域。"
```
