## 图1 SHAP框架原理图（第2.2.1节）

### 图表功能

### 整体布局
- **类型**: 横向流程图（左→右）
- **尺寸**: 12×6英寸（横屏）
- **层次**: 三层结构（输入层→计算层→输出层）

### 必需元素

#### 第一层：输入层（左侧，蓝色系）

2. **训练数据集框**

### 关键相互作用箭头

**促进关系（实线箭头→，红色）**
- COD → 污染等级（粗箭头）
- BOD → 污染等级
- TN → 污染等级
- TP → 污染等级
- 浊度 → 污染等级
- 重金属 → 污染等级

**抑制关系（实线箭头→带⊥，蓝色）**
- DO → 污染等级（负相关，箭头末端加⊥符号）
- 有机物↑ → DO↓（正反馈环，用曲线箭头表示）

**转化关系（虚线箭头⇢，绿色）**
- NH₃-N ⇢ NO₂⁻ ⇢ NO₃⁻（氮循环）
- pH影响重金属溶解度（虚线双向箭头）

**协同效应（双箭头↔，橙色）**
- COD ↔ 浊度（协同污染）
- TN ↔ TP（富营养化）

### 反馈环标注
1. **正反馈环1**: 有机物↑ → 微生物分解↑ → DO消耗↑ → 缺氧↑ → 有机物积累↑
   - 用红色曲线环绕，标注"R1 加剧恶化"

2. **负反馈环2**: DO↑ → 微生物活性↑ → 有机物降解↑ → DO消耗↑ → DO↓
   - 用蓝色曲线环绕，标注"B1 自净调节"

### 缓冲系统框
15. **pH缓冲系统**（独立虚线框）
    - 内容: "碳酸盐缓冲\nCO₂-HCO₃⁻-CO₃²⁻"
    - 位置: 图表左下角单独区域
    - 说明: pH与其他指标相关性弱的原因

### 图例
- ✓ 实线箭头→: 促进/正相关
- ✓ 实线箭头⊥: 抑制/负相关
- ✓ 虚线箭头⇢: 化学转化

- ✓ 曲线环R: 正反馈环（Reinforcing）

## 图14 评估指标体系框架图（第4.5.2节）

### 图表功能

3. **回归评估分支**
   - 内容: "回归任务评估"
   - 目标: "水质指标数值预测"
   - 形状: 矩形
   - 颜色: 绿色系（#32CD32）

#### 第2层：分类指标子树（左侧）

**节点2-1: 整体性能**
4. **准确率节点**
   - 公式: Accuracy = (TP+TN) / Total
   - 范围: [0, 1]
   - 最优值: 1.0
   - 适用: 类别均衡场景
   - 颜色: 浅蓝色（#ADD8E6）

**节点2-2: 类别粒度**
5. **精确率节点**
   - 公式: Precision = TP / (TP+FP)
   - 意义: 预测为正类的可信度
   - 适用: 重视误报成本
   - 颜色: 浅蓝色（#ADD8E6）

6. **召回率节点**
   - 公式: Recall = TP / (TP+FN)
   - 意义: 真正类被识别的比例
   - 适用: 重视漏报成本（如污染预警）
   - 颜色: 浅蓝色（#ADD8E6）

7. **F1分数节点**
   - 公式: F1 = 2PR/(P+R)
   - 意义: 精确率和召回率的调和平均
   - 适用: 类别不均衡场景
   - 颜色: 浅蓝色（#ADD8E6）

**节点2-3: 详细诊断**
8. **混淆矩阵节点**
   - 内容: 5×5矩阵示意
   - 意义: 展示所有类别间的误分类模式
   - 对角线: 正确分类
   - 非对角线: 误分类
   - 颜色: 浅蓝色（#ADD8E6）

#### 第3层：回归指标子树（右侧）

**节点3-1: 方差解释**
9. **R²节点**
   - 公式: R² = 1 - SS_res/SS_tot
   - 范围: (-∞, 1]
   - 最优值: 1.0
   - 意义: 模型解释的方差比例
   - 适用: 评估整体拟合质量
   - 颜色: 浅绿色（#90EE90）

**节点3-2: 绝对误差**
10. **MAE节点**
    - 公式: MAE = mean(|y-ŷ|)
    - 范围: [0, +∞)
    - 最优值: 0
    - 意义: 平均偏差（与y同单位）
    - 适用: 关注误差绝对大小
    - 颜色: 浅绿色（#90EE90）

**节点3-3: 平方误差**
11. **RMSE节点**
    - 公式: RMSE = sqrt(mean((y-ŷ)²))
    - 范围: [0, +∞)
    - 最优值: 0
    - 意义: 对大误差敏感（与y同单位）
    - 适用: 惩罚极端预测误差
    - 颜色: 浅绿色（#90EE90）

## 图表绘制通用学术规范（所有图表适用）

### 分辨率要求
- **最低要求**: 300 DPI
- **推荐**: 600 DPI（用于高质量期刊出版）
- **格式**: PNG（透明背景）或PDF矢量图

### 字体规范
- **中文**: 黑体（SimHei）或微软雅黑
- **英文**: Arial或Helvetica
- **数学公式**: Times New Roman或Computer Modern
- **字号**:
  * 图表标题: 14-18pt
  * 主要标签: 10-12pt
  * 次要标签/注释: 8-9pt

### 颜色规范
- **主色调**: 避免过于鲜艳的颜色，使用专业学术配色
- **色盲友好**: 避免红绿组合，推荐蓝橙组合
- **打印友好**: 确保黑白打印时仍可区分（使用不同灰度或纹理）
- **对比度**: 文字与背景对比度≥4.5:1

### 线条规范
- **外框**: 2pt实线
- **内部分隔线**: 1-1.5pt实线或虚线
- **箭头**: 2-3pt，实心三角箭头
- **连接线**: 1.5pt实线

### 尺寸规范
- **单栏图**: 宽度≤3.5英寸
- **双栏图**: 宽度≤7英寸
- **全页图**: 宽度≤8.5英寸，高度≤11英寸

### 标注规范
- **图题**: 置于图下方，格式"图X 图表名称"
- **图注**: 置于图题下方，格式"*注，图X展示了..."
- **图例**: 置于图内右上角或图外右侧
- **数据来源**: 标注在图注中

### 文件命名规范
- 格式: `章节编号_简短描述.png`
- 示例: `2.2.1_shap_framework.png`
