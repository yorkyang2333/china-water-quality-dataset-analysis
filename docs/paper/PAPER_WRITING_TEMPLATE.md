# 学术论文写作模板与规范

**适用范围**：水质污染数据分析项目论文及类似学术写作
**创建日期**：2025-11-23
**版本**：1.0

---

## 一、核心写作原则

### 1.1 数据呈现原则

**❌ 错误做法**：
- 提及数据但不展示具体数值
- 让读者去查看项目文件夹或外部目录
- 使用"详见XX目录"的模糊表述

**✅ 正确做法**：
- 所有关键数据必须在论文中直接展示
- 使用表格呈现结构化数据
- 数据表格应包含：
  - 清晰的中文标题（表1、表2...）
  - 完整的单位标注
  - 必要的描述性信息
  - 合理的列数（建议3-6列）

**示例**：

```markdown
❌ 错误：
"污染等级分布详见数据集统计文件。"

✅ 正确：
"表3展示了各污染等级的详细分布情况。

**表3 污染等级分布**

| 污染等级 | 样本数量 | 百分比 | 特征描述 |
|---------|---------|--------|---------|
| 优 (Excellent) | 3,015 | 19.4% | 水质优良，各项指标表现突出 |
| 良 (Good) | 8,280 | 53.3% | 水质良好，占据主导地位 |
...
```

---

### 1.2 内容深度原则

**❌ 错误做法**：
- 每个小节只有1-2段简单描述
- 方法部分只列举名称，不解释原理
- 缺少"为什么这样做"的说明

**✅ 正确做法**：
- 每个小节至少3-5段详细叙述
- 包含方法的原理、选择理由、实施步骤
- 补充背景知识和应用价值
- 增加承上启下的过渡句

**扩充层次**：
1. **是什么**：方法/指标的定义和背景
2. **为什么**：选择该方法的理由和优势
3. **怎么做**：具体的实施步骤和参数设置
4. **有何用**：对实际问题的意义和价值

**段落结构建议**：
- 第1段：引入背景，说明重要性
- 第2-3段：详细描述方法/数据/结果
- 第4段：分析原因或讨论意义
- 第5段（可选）：与其他方法/地区的对比

---

### 1.3 真实性原则

**❌ 严禁虚构的内容**：
- ❌ 项目中未实现的方法（如孤立森林、LSTM自编码器）
- ❌ 未经验证的统计量（如K-means聚类结果）
- ❌ 编造的精确数字（如59.09%这样无法验证的数字）
- ❌ 未实际执行的分析步骤

**✅ 确保真实性的检查清单**：
- [ ] 所有统计数字是否来自实际数据计算？
- [ ] 所有方法是否在项目代码中实现？
- [ ] 所有分析结果是否有对应的输出文件？
- [ ] 是否可以通过代码复现论文中的每个数字？

**验证方法**：
1. 数据统计：运行Python脚本验证每个数字
2. 方法实现：检查相关代码文件是否存在
3. 结果输出：确认输出目录中有对应的结果文件

---

### 1.4 学术风格原则

**❌ AI味重的表达**：
- "三种方法""四个维度"的机械列举
- 过度精确的百分比（59.09%）
- 无上下文的数学公式堆砌
- "低污染、中等污染、较高污染"的生硬分类
- 使用"首先...其次...最后..."的流水账结构

**✅ 自然学术叙述**：
- 用流畅的段落描述替代简单列举
- 增加承上启下的过渡句
- 说明方法选择的理由（而非只是"用了什么"）
- 使用"约59%"或删除无法验证的数字
- 变化句式，避免重复的结构

**对比示例**：

```markdown
❌ AI味重：
异常值检测综合使用四分位距法（IQR）、孤立森林和LSTM自编码器三种方法。
首先，使用IQR方法。其次，使用孤立森林。最后，使用LSTM自编码器。

✅ 自然学术：
本研究采用了两种经典的统计学方法进行异常值检测。一是基于正态分布假设的
3-sigma原则，将超出均值±3倍标准差范围的观测标记为潜在异常值。二是四分
位距方法（IQR），通过计算第25百分位数（Q1）和第75百分位数（Q3），将低于
Q1−1.5×IQR或高于Q3+1.5×IQR的数据视为异常。考虑到环境监测数据可能存在
的真实极端事件（如突发污染事故），本研究采取了较为保守的策略...
```

## 二、具体写作要求

### 2.1 数据与方法章节

#### 数据集描述部分

**必须包含的表格**：
- [ ] 数据集基本特征表（样本量、站点数、时间范围等）
- [ ] 指标列表及单位表（可选，如指标较多）
- [ ] 时间/空间分布统计表

**必须包含的内容**：
1. 数据来源和背景（1段）
2. 地理覆盖和代表性（1段）
3. 指标详细说明，分类列举（2-3段）
4. 工程特征的创建及意义（1段）
5. 数据特征（采样频率、时间分布等，1段）

#### 数据预处理部分

**必须包含的表格**：
- [ ] 有效范围参数表（各指标的取值范围及依据）
- [ ] 预处理步骤统计表（可选，如数据量变化）

**必须包含的内容**：
1. 预处理的重要性和流程概述（1段）
2. 基于理论范围的过滤（1段 + 表格）
3. 统计学异常值检测方法（1-2段，详细描述）
4. 数据规范化处理（1段）
5. 最终数据集统计（1段）

#### 分布特征部分

**必须包含的表格**：
- [ ] 污染等级分布表（各等级的样本数和百分比）
- [ ] 省份/区域统计表（如水质指数排名）
- [ ] 主要指标描述性统计表（均值、标准差、偏度等）

**必须包含的内容**：
1. 类别分布分析（1-2段 + 表格）
2. 地理差异分析（1-2段 + 表格）
3. 指标分布特征（1-2段 + 表格）
4. 时间分布特征（1段）

#### 方法描述部分

**必须包含的内容**：
1. 问题形式化：任务定义、输入输出、评价指标（2-3段）
2. 横截面方法：
   - 方法选择理由（1段）
   - 特征工程详细说明（1-2段）
   - 类别不均衡处理（1段）
   - 回归任务特点（1段）
3. 时间序列方法（如适用）：
   - 方法列举和架构（1段）
   - 适用性分析（1段）
4. 可解释性方法：
   - SHAP原理和优势（1-2段）
   - 分析角度和可视化工具（2-3段）
   - 实际应用价值（1段）

### 2.3 图片与可视化

#### 图片文件管理规范

**目录结构**：
```
docs/
├── PAPER_MANUSCRIPT_CN.md          # 论文主文件
└── resources/
    └── chapter[X]_[section_name]/  # 按章节组织
        ├── 3.1.3_sampling_interval_distribution.png
        ├── 3.2.4_shap_classification_summary.png
        └── README_MISSING_IMAGES.md  # 缺失图片说明
```

**文件命名规范**：
- 格式：`[章节号].[小节号]_[图片英文描述].png`
- 示例：`3.1.3_acf_plot.png`、`3.2.4_cod_dependence.png`
- 优先使用PNG格式（DPI=300，适合学术出版）

**图片质量要求**：
- 分辨率：DPI ≥ 300
- 中文字体：使用黑体（SimHei），通过zhplot库配置
- 无emoji符号（避免编码问题）
- 清晰的坐标轴标签和图例

```markdown
高度分散的分布，变异系数CV=1.99远超规则采样的阈值（CV<0.2），证明了数据采样的
```

**示例2 - SHAP分析图**：

```markdown
图6和图7从不同角度展示了分类任务中各特征的SHAP重要性分析结果。
```

#### 图注写作要求

**✅ 优秀图注的四要素**：

1. **图表结构说明**（1-2句）
   - 说明图表类型（柱状图、散点图、箱线图等）
   - 解释横纵轴含义
   - 说明颜色/符号的编码规则

2. **关键发现与数值引用**（2-3句）
   - 指出图中最显著的模式
   - 引用具体数值（如"CV=1.99"、"ACF(1)=0.03"）
   - 对比不同区域/类别的差异

3. **数据解读与原因分析**（1-2句）
   - 解释现象背后的原因
   - 联系理论知识或先验经验
   - 指出与预期的一致性或差异

4. **实际意义与应用价值**（1句）
   - 说明该发现对研究结论的支撑
   - 提炼可操作的管理建议（如"COD=20 mg/L可作为预警阈值"）
   - 指出对未来工作的启示

**❌ 错误的图注示例**：
```markdown
*注：图3展示了ACF图。*
（过于简单，没有任何解读）
```

**✅ 正确的图注示例**：
```markdown
*注：图3展示了水质指标的自相关函数（ACF）随滞后阶数的变化。一阶自相关系数
ACF(1)=0.03接近零，远低于通常认为有效的阈值（0.3），表明当前观测值与前一时刻
观测值之间几乎没有线性关系。这一结果进一步验证了采样不规则性导致的时间依赖性
缺失，为选择横截面预测方法而非时间序列方法提供了数据支撑。*
```

#### 图片位置安排原则

**插入位置**：
1. **数据表格之后**：先用表格呈现结构化数据，再用图片可视化
2. **相关段落之后**：在描述某现象的段落后立即插入对应图片
3. **分析段落之前**：先展示图片，再进行详细分析

**引用方式**：
- 在正文中必须先提及图片（"如图X所示"、"图X展示了..."）
- 图片编号连续（图1、图2、图3...）
- 避免将图片放在章节开头（应先有文字引入）

**对比示例**：

```markdown
❌ 错误布局：
## 3.1.3 采样不规则性分析
![图2 采样间隔分布](...)
对连续采样间隔的分析揭示了严重的不规则性...

✅ 正确布局：
## 3.1.3 采样不规则性分析
对连续采样间隔的分析揭示了严重的不规则性。平均间隔7天，标准差16天，
最大间隔达253天，变异系数CV=1.99。根据既定标准（Hyndman & Athanasopoulos, 2018），
CV>1.0表明极度不规则，时间序列方法不适用。
```

## 四、常见错误与修正

### 错误1：缺乏具体数据

**症状**：
- "污染等级分布不均衡"（但不给出具体数字）
- "详见XX目录"
- "结果表现良好"（不给出具体指标）

**修正**：
- 添加数据表格直接展示
- 在正文中引用表格（"如表X所示"）
- 给出具体的数字和百分比

---

### 错误2：内容过于简单

**症状**：
- 每个小节只有1-2段
- 只列举方法名称，不解释原理
- 缺少"为什么"的说明

**修正**：
- 扩充为3-5段
- 补充方法原理和选择理由
- 增加应用价值和实际意义
- 添加与其他方法的对比

---

### 错误3：虚构内容

**症状**：
- 提到项目中不存在的方法
- 给出无法验证的统计量
- 过度精确的百分比（如59.09%）

**修正**：
- 删除未实现的方法
- 运行代码验证每个数字
- 降低精度或删除无法验证的数字
- 标注探索性结果的不确定性

---

### 错误4：AI味重

**症状**：
- "三种方法""四个维度"
- "首先...其次...最后..."
- 数学公式堆砌
- 生硬的分类表述

**修正**：
- 改为自然段落叙述
- 融入方法的背景和理由
- 增加过渡句
- 使用更多样化的句式

---

### 错误5：图片使用不当

**症状**：
- 图片在正文中未提及就直接插入
- 图注过于简单（"图X展示了XX"）
- 图片路径错误或文件不存在
- 图片编号不连续或重复
- 缺少图注中的数据解读

**修正**：
- 在正文段落中先引入图片（"图X展示了..."）
- 编写详细图注（包含四要素：结构+发现+解读+意义）
- 检查图片路径和文件存在性
- 统一图片编号（图1、图2、图3...）
- 在图注中引用具体数值和关键发现

**对比示例**：
```markdown
❌ 错误：
![图3 ACF图](resources/acf.png)
*注：图3展示了ACF图。*

✅ 正确：
图3展示了水质指标的自相关函数（ACF）随滞后阶数的变化。

![图3 自相关函数（ACF）图](resources/chapter3_data_methods/3.1.3_acf_plot.png)

*注：图3展示了水质指标的自相关函数（ACF）随滞后阶数的变化。一阶自相关系数
ACF(1)=0.03接近零，远低于通常认为有效的阈值（0.3），表明当前观测值与前一时刻
观测值之间几乎没有线性关系。这一结果进一步验证了采样不规则性导致的时间依赖性
缺失，为选择横截面预测方法而非时间序列方法提供了数据支撑。*
```

### 示例2：方法描述（自然叙述）

```markdown
横截面预测方法将每条观测记录视为独立样本，通过水质指标之间的空间关联性来
建立预测模型。这种方法特别适合本研究所使用的数据集，因为如3.1.3节所述，数据
采样的高度不规则性使得传统时间序列方法难以发挥作用。本研究主要采用基于树的
集成学习算法，包括XGBoost、RandomForest、LightGBM和CatBoost四种模型，它们
在处理复杂非线性关系和高维特征时表现出色，且对异常值具有较好的鲁棒性。

模型的输入特征包括三个层次的信息。首先是17个原始水质指标，它们构成了预测的
基础。其次是地理位置信息，通过省份标签的独热编码（One-Hot Encoding）以及监测
站点的经纬度坐标，将空间异质性纳入模型考虑范围...
```

**优点**：
- 说明方法适用性（为什么选择）
- 列举模型的同时说明优势
- 自然过渡，避免生硬列举
- 层次分明（三个层次融入段落中）

## 六、快速参考卡片

### ✅ 写作自检五问

1. **数据在哪？** → 论文中有表格直接展示吗？
2. **图片在哪？** → 关键发现有可视化图片支撑吗？
3. **够详细吗？** → 每个小节至少3-5段吗？
4. **是真实的吗？** → 所有数字、方法和图片都能在项目中找到吗？
5. **像人写的吗？** → 避免"三种方法""四个维度"了吗？

### ❌ 禁止使用的表达

- "详见XX目录"
- "三种方法""四个维度"
- "首先...其次...最后..."（连续使用）
- 无法验证的精确百分比（XX.XX%）
- 项目中不存在的方法名
- "图片见附件"（应直接嵌入论文）

### ✅ 推荐使用的表达

**数据呈现**：
- "表X展示了..."
- "如表X所示..."

**图片引用**：
- "图X展示了..."
- "如图X所示..."
- "图X和图Y分别展示了..."

**方法描述**：
- "本研究采用了...方法"
- "这种方法的优势在于..."
- "约XX%"或"XX%左右"
