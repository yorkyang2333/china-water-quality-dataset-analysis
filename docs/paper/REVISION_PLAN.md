## 一、修改背景与用户决策

### 审稿意见核心问题
1. **致命逻辑漏洞（⭐⭐⭐⭐⭐）**: 分类任务用定义污染等级的化学指标预测等级，本质是逆向工程GB 3838-2002规则表
2. **数据一致性矛盾（⭐⭐⭐⭐）**: 表15准确率99.58% vs 表15-B准确率74.75%，特征集差异说明不清
3. **贝叶斯网络循环论证（⭐⭐⭐）**: "城市化指数"由COD+氨氮构建，结论却说"城市化导致污染"
4. **回归任务价值模糊（⭐⭐⭐）**: 摘要报告R²=0.97，但正文显示特征独立约束下仅0.50
5. **特征集透明度不足（⭐⭐⭐）**: 全特征vs简化特征的具体差异未明确列出

### 用户选择的修改策略

#### 3.4 第6.3节 - 局限性补充（第1015行后）

**新增5点局限性**：

1. **分类任务逻辑边界**（第1016行后）：
```
在方法层面，本研究分类任务的高准确率（99.58%）存在逻辑边界。由于输入
特征包含COD、氨氮、溶解氧等定义污染等级的化学指标，模型本质上是学习
GB 3838-2002规则表的if-else逻辑，而非发现水质变化的潜在规律。这种
"拟合规则表"的模式虽然达到接近完美的性能，但学术创新性有限。低成本
传感器实验（6个物理指标，78%准确率）才是真正的预测任务，具有工程
应用价值但性能较低。
```

2. **回归任务性能局限**：
```
回归任务在特征独立约束下仅COD达到R²=0.50的"中等"水平，其余6个指标
均失败（R²<0.1或为负）。这说明横截面方法的适用性高度依赖特征间相关性：
当目标指标与可用特征存在中等相关（r=0.4-0.6）时可部分成功，但弱相关
（r<0.4）时基本无效。这一局限性限制了横截面回归在实际应用中的推广。
```

3. **贝叶斯网络因果推断局限**：
```
贝叶斯网络分析采用的代理变量方法存在根本性局限。"有机污染负荷"本质上
是COD和氨氮的加权组合，属于水质指标而非社会经济指标。因此，观察到的
"高有机污染负荷与高大肠菌群风险"关联，反映的是不同污染指标的共变关系
（共同来源于生活污水），而非外部环境因素的因果影响。本研究将此定位为
探索性关联分析，而非严格的因果推断。
```

4. **空间泛化有限性**：
```
虽然按站点分割实验显示准确率仅下降1%（74.75%→73.77%），但测试站点
仍属于同一监测网络，可能共享相似的地理气候和污染源特征。在完全不同的
流域或气候区（如长江流域模型应用于黄河流域），性能可能显著下降。
```

5. **时间泛化挑战**：
```
数据集时间分布严重失衡（2023年89%，2024年11%），且仅覆盖2年时间跨度。
模型对长期气候变化、政策效应、污染源演变等因素的适应能力未经验证。在
水环境发生显著变化时（如新建污水处理厂、产业结构调整），模型需要重新
训练以维持性能。
```

## 五、写作指南与质量控制

### 避免AI味的5个原则

1. **用数据代替形容词**
   - ❌ "显著提升"
   - ✅ "准确率从74.75%提升至78%"

2. **诚实报告局限性**
   - ❌ "模型表现优异"
   - ✅ "准确率78%，较全指标下降22个百分点"

3. **避免因果断言**
   - ❌ "城市化导致大肠菌群污染"
   - ✅ "高有机污染负荷条件下，大肠菌群风险概率为59%"

4. **框架化而非夸大**
   - ❌ "突破性成果"
   - ✅ "在成本-性能权衡中找到实用平衡点"

5. **承认方法边界**
   - ❌ "适用于所有场景"
   - ✅ "适用于实时预警，不适用于法规评估"

### 低成本预测价值框架

**核心叙事**: 不是"性能妥协"，而是"场景匹配"

| 场景 | 推荐方案 | 理由 |
