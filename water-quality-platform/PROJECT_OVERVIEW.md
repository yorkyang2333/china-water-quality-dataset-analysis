# 项目概览 | Project Overview

## 🎯 项目定位

**水质监测可视化平台** 是一个集成数据管理、模型服务、可视化展示的全流程Web应用，采用前后端分离架构，专为水质监测数据分析和预测而设计。

---

## ✨ 核心特色

### 1️⃣ 动态地图展示
```
✅ 实时渲染180+监测站点
✅ 按污染等级（5级）分层显示
✅ 颜色编码 + 图标大小动态调整
✅ 聚类优化，支持大数据量
```

### 2️⃣ 时间轴控制
```
✅ 选择任意时间段
✅ 查看水质历史变化
✅ 趋势图表可视化
✅ 支持日/周/月聚合
```

### 3️⃣ 空间查询
```
✅ 矩形框选工具
✅ 圆形选择工具
✅ 实时统计选定区域
✅ 自动计算平均值
```

### 4️⃣ AI预测服务
```
✅ 污染等级预测（基于XGBoost，99.5%准确率）
✅ 水质指标预测（时序预测）
✅ 概率分布显示
✅ RESTful API接口
```

## 🌟 主要功能模块

### 后端API（8个端点）

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/stations` | GET | 获取所有监测站点 |
| `/api/data/timeline` | GET | 获取时间轴数据 |
| `/api/data/spatial` | POST | 空间查询 |
| `/api/predict/pollution_level` | POST | 预测污染等级 |
| `/api/predict/water_quality` | POST | 预测水质指标 |
| `/api/statistics/summary` | GET | 统计摘要 |
| `/api/trends` | GET | 趋势数据 |
| `/` | GET | 返回前端页面 |

### 前端模块（3个JS文件）

| 文件 | 功能 |
|------|------|
| `map.js` | 地图核心、站点渲染、空间查询 |
| `timeline.js` | 时间轴控制、趋势图表 |
| `prediction.js` | 预测表单、结果展示 |
