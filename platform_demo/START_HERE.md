# 快速启动指南 | Quick Start Guide

## 🚀 启动步骤

### 1. 进入项目目录
```bash
cd platform_demo
```

### 2. 启动服务器
```bash
python run.py
```

### 3. 访问平台
在浏览器中打开: **http://localhost:5000**

## 🎯 使用示例

### 查看实时监测
1. 点击左侧边栏"实时监测"标签
2. 查看7个指标的实时状态
3. 关注红色🚨危险状态的指标

### 查看告警信息
1. 点击左侧边栏"告警信息"标签
2. 查看严重告警数量（红色）
3. 滚动查看详细告警列表

### 省份筛选联动
1. 在控制面板选择省份（如"北京"）
2. 所有面板自动更新为该省份数据
3. 图表自动重新渲染

### 数据质量监控
1. 点击右侧边栏"数据质量"标签
2. 查看质量评分圆环
3. 查看各指标完整性进度条
